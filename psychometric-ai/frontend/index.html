Architecture

Deterministic engine vs LLM explanation layer

The LLM never calculates scores, ranks, or bands. All math runs in deterministic backend engines with versioned, database-driven weights. The LLM only receives the final structured JSON and writes plain-language explanations — and its output is sanitized before display.
